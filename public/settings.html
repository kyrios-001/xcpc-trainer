如何获取洛谷 Cookie（Chrome / Edge）
  1. 浏览器打开 luogu.com.cn 并登录账号；
  2. 按 F12 → 切到 Network / 网络 标签 → 刷新页面（F5）；
  3. 点列表里任意一条请求 → 右侧 Headers / 标头 → 找 Request Headers / 请求标头 里的 Cookie: 那一行；
  4. 复制 Cookie: 冒号后面的整段（形如 __client_id=...; _uid=...; C3VK=...），粘贴到上方输入框。只复制一条 Cookie 不够，必须整段。
